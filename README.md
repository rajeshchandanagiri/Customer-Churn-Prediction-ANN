# Customer Churn Prediction using ANN

## Project Overview

This project predicts whether a customer is likely to leave a bank using an Artificial Neural Network (ANN).

The project uses customer demographic, financial, and account-related information to predict the Exited target variable.

## Dataset

The dataset contains customer information such as:

- Credit Score
- Geography
- Gender
- Age
- Tenure
- Balance
- Number of Products
- Has Credit Card
- Is Active Member
- Estimated Salary

### Target Variable

Exited

0 → Customer did not leave
1 → Customer left
